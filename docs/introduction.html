何ができるか

S3 オブジェクトを探す

バケット検索、Prefix 階層表示、ローカルフィルタ、名前順 / 更新順ソートで目的の key を素早く見つけられます。

安全に確認・編集する

起動直後は保存 OFF。テキスト、JSON、YAML、CSV、env ファイルを確認し、差分を見てから保存できます。

画像・PDF をプレビュー

JPEG、PNG、WebP、GIF、PDF を Web UI で確認できます。大きいファイルはダウンロードで扱います。

アップロードとコピー

単体/複数ファイル、ドラッグ&ドロップ、選択中オブジェクトの別 key コピーに対応しています。

お気に入りと履歴

よく使うバケットやオブジェクトをお気に入り登録し、最近使ったバケット / Prefix に戻れます。

CLI でも使える

list, head, get, show, diff, edit, put, copy を用意しています。

安全設計

認証情報はブラウザに渡さない

ブラウザは localhost の API にアクセスし、S3 操作は Node.js サーバー側で実行します。

ローカル専用

Web UI は 127.0.0.1 で待ち受けます。共有サーバーとして使う設計ではありません。

書き込みは明示的に有効化

保存 ON、バケット作成、上書き確認、CSRF / Origin チェックで誤操作を減らします。

Web UI と CLI の関係

Web UI はローカル API を呼ぶ

ブラウザは http://127.0.0.1:5174 で配信される画面から、同じローカルサーバーの /api/... だけを呼び出します。S3 へのアクセスや認証情報の読み込みはサーバー側で行います。

CLI と同じ中核処理を使う

Web UI サーバーと CLI は、設定読み込み、S3 操作、Content-Type 判定、認証期限切れ時の再試行などの共通モジュールを利用します。

CLI を直接実行しない

Web UI が CLI を別プロセスとして叩くのではなく、両方が同じ実装を共有する構成です。動作の一貫性を保ちつつ、ブラウザ側に認証情報を出しません。

GET /api/config起動時の設定、保存可否、CSRF トークンを取得します。
GET /api/buckets認証情報で参照できるバケット一覧を取得します。
GET /api/list?bucket=...&prefix=...指定バケット / Prefix のオブジェクト一覧を取得します。
GET /api/object?bucket=...&key=...選択したオブジェクトのメタデータと、編集可能なテキスト本文を取得します。
GET /api/raw?bucket=...&key=...画像や PDF のプレビュー用にオブジェクト本文を返します。
POST /api/save保存 ON の時だけ、テキスト編集内容を S3 に保存します。
POST /api/upload保存 ON の時だけ、ローカルファイルを S3 にアップロードします。
POST /api/copy保存 ON の時だけ、選択オブジェクトを別 key にコピーします。

試し方

git clone https://github.com/koyamasoft/s3-file-manager.git cd s3-file-manager npm ci npm run build npm run web
起動後は http://127.0.0.1:5174 を開きます。AWS S3 を使う場合は、先に aws sts get-caller-identity で認証情報を確認してください。
